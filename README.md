# B-Dali — Bilingual Ordering Demo

واجهة طلبات متجاوبة بهوية B-Dali (الأحمر/الأسود/الأبيض)، العربية والفرنسية.

## الموجودة في هذه النسخة
- قائمة تجريبية، بحث وتصنيفات
- سلة مع تعديل الكميات والمجموع
- طلب كضيف دون إنشاء حساب
- نموذج اسم/هاتف/عنوان/ملاحظة
- الدفع نقدًا عند الاستلام
- تحويل تفاصيل الطلب إلى WhatsApp
- manifest وservice worker كنقطة بداية لتجربة PWA

## معلومات مهمة قبل النشر
هذه **نسخة Front-end تجريبية**. زر تأكيد الطلب يفتح WhatsApp لإرسال الطلب، ولا يخزّن الطلبات في قاعدة بيانات بعد. الحسابات الاختيارية، الطلب المباشر المحفوظ، لوحة الإدارة، وإدارة شركة التوصيل تتطلب Backend وقاعدة بيانات (مثل Supabase) وسيتم إعدادها كمرحلة منفصلة.

القائمة والأسعار والصور ومعلومات الاتصال تجريبية ويجب تأكيدها مع B-Dali. رقم WhatsApp المستخدم في رابط الطلب مأخوذ من معلومات ظهرت في التصميم السابق، يرجى التأكد منه قبل الإطلاق.

## نشر النسخة التجريبية
يمكن رفع محتويات هذا المجلد إلى GitHub ثم استيراد Repository في Vercel. ملف البداية هو `index.html`.
